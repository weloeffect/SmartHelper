# Get started with SmartHelper

SmartHelper organizes work into workspaces, projects, and tasks. A workspace contains one or more projects. Every task belongs to exactly one project.

## Create a workspace

1. Select **Create workspace** from the workspace switcher.
2. Enter a workspace name and choose its time zone.
3. Select **Create**. The creator becomes the workspace Owner.

A workspace name can be changed later in **Settings > Workspace**. The time zone controls the dates shown in activity emails; it does not change a task's stored due date.

## Create a project and task

From a workspace, select **New project**, enter a name, and choose **Create**. Open the project and select **New task**. A task requires a title; description, assignee, due date, and labels are optional. A task can have one assignee and up to five labels.

## Invite a teammate

Open **Settings > Members > Invite members**, enter the email address, select a role, and send the invitation. Invitations expire after seven days. A workspace Admin or Owner can resend an expired invitation.

For role details, see [Workspaces, roles, and permissions](workspaces-and-roles.md). For invitation problems, see [Troubleshoot invitations and notifications](../support/troubleshooting.md).
